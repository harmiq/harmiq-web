Cubase

Una DAW muy completa para composición, grabación, edición, MIDI y mezcla, especialmente fuerte cuando el proyecto necesita mucho control de audio.

De pago · Elements / Artist / Pro

¿Para qué tipo de música es buena?

🎤 Pop y rock

Muy cómoda para grabar voces, guitarras, baterías y hacer edición detallada.

🎼 Composición

Chord Track, Chord Assistant y herramientas MIDI ayudan a construir armonías y arreglos.

🎬 Bandas sonoras

Su combinación de MIDI, audio y edición la hace válida para proyectos complejos.

🎚️ Mezcla

MixConsole, routing y automatización ofrecen un entorno muy completo de mezcla.

Funciones que conviene entender

VariAudio

Herramientas avanzadas para editar afinación y expresión vocal en las ediciones que lo incluyen.

Separación de stems

Cubase Pro incorpora separación de stems para trabajar con componentes independientes de una grabación.

Chord Track

Permite trabajar con progresiones y armonía sin tener que editar cada nota manualmente desde cero.

MixConsole

Es el centro de mezcla para controlar canales, buses, efectos y automatización.

¿Qué pasa con la IA?

Steinberg utiliza aprendizaje automático en funciones concretas como la separación de stems. Importante: “Cubase AI” es también el nombre de una edición compacta vinculada a determinados productos Steinberg/Yamaha; no significa que Cubase sea una DAW generativa.

¿A quién se la recomendaría?

Si quieres una DAW tradicional pero muy potente, con mucho control sobre audio, MIDI, voces y mezcla, Cubase es una candidata especialmente sólida.
